# Portfolio — Aaron Wuler

Mi web personal: moda, ecommerce y software.

Hecha con Next.js + TypeScript, exportada como sitio estático.

## Correrlo

```bash
npm install
npm run dev
```

Para generar la versión estática: `npm run build` (queda en `out/`).

## Dónde está cada cosa

- `src/contenido.ts` → todos los textos, proyectos, skills y links. Para cambiar algo o sumar un proyecto, se edita solo este archivo.
- `src/components/` → una sección por archivo (Hero, Sobre, Experiencia, Proyectos, Skills, Ahora, Contacto).
- `src/app/proyectos/raw-design/` → el case study de RAW Design.
- `public/fotos/` → fotos y capturas.
- `src/fonts/` → Archivo y JetBrains Mono en local.
